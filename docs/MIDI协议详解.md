# MIDI 协议详解

## 一、MIDI 是什么

**Musical Instrument Digital Interface**（乐器数字接口）。1983 年发明的协议，用来让电子乐器、电脑、调音台互相"说话"。

它**不传输声音**，只传输"演奏指令"——相当于乐谱不是声音。

比如你弹一下钢琴琴键，MIDI 设备发的不是一段音频，而是：**"第 5 轨道，弹 C4 这个音，力度 127"**。

这就是为什么我们这个工具叫"调试工具"——它截获的是这些指令，不是声音。

---

## 二、消息结构：每条 MIDI 都是一串字节

MIDI 消息最短 2 字节，最长 3 字节。本工具日志里的 `raw_hex` 列显示的就是原始字节。

### 状态字节（第一个字节）告诉我们"是什么类型的消息"

```
高 4 位 = 消息类型
低 4 位 = 通道号（0-15）
```

### 两类消息

| 大类 | 类型 | 说明 |
|---|---|---|
| **Channel 消息**（有通道号） | Note On / Note Off / CC / Pitch Bend / Program Change / Aftertouch | 占 90%，日常打交道的都是它 |
| **System 消息**（无通道号） | Sysex / Song Position / Song Select / Clock / Start/Stop | 少用，主要给鼓机/合成器同步 |

---

## 三、Channel（通道）详解

### 什么是通道

MIDI 有 **16 个通道**（Channel 1 ~ 16），每个通道相当于一条"独立管线"。

| 日志显示 | 内部值 | 含义 |
|---|---|---|
| `CH1` | 0 | 第 1 通道 |
| `CH2` | 1 | 第 2 通道 |
| ... | ... | ... |
| `CH16` | 15 | 第 16 通道 |

> **注意差一！** 协议里是 0-15，人类可读写成 1-16。日志里 `CH0` 其实是第 1 通道，`CH9` 是第 10 通道。

### 通道用来干嘛

最经典的分工是 GM（General MIDI）标准：

| 通道 | 用途 |
|---|---|
| 1 | 旋律主音 |
| 2 | 贝斯 |
| 3 | 和声铺底 |
| 4-8 | 其他声部 |
| **10（内部 9）** | **打击乐专用**（鼓组每个音符=不同乐器） |
| 11-16 | 其他声部 |

## 四、Channel 消息类型逐个讲

### 🔵 Note On — 音符开（按下琴键）

```
字节: 0x90 + channel  | note  | velocity
日志: note_on ch0 note=60 vel=127
hex : 90 3C 7F
```

| 字段 | 范围 | 含义 |
|---|---|---|
| **channel** | 0-15 | 在哪个通道弹 |
| **note** | 0-127 | 弹哪个音（0=C-1，60=C4 中央 C，127=G9） |
| **velocity** | 1-127 | 触键力度（越大越响）。**127 是强奏，1 几乎听不见** |

**注意**：velocity=0 的 Note On 等价于 Note Off —— 有些设备用这种方式表示松手，不用单独发 Note Off。

### 🔵 Note Off — 音符关（松开琴键）

```
字节: 0x80 + channel  | note  | release_velocity
日志: note_off ch0 note=60 vel=64
hex : 80 3C 40
```

| 字段 | 范围 | 含义 |
|---|---|---|
| **note** | 0-127 | 松的哪个音 |
| **release_velocity** | 0-127 | 松手的速度（有些键盘不支持，固定发 64） |

### 🟢 CC — Control Change（控制改变）

```
字节: 0xB0 + channel  | control  | value
日志: cc ch0 cc=21 val=127
hex : B0 15 7F
```

这是**最灵活的消息类型**——用来表达"除了弹音符之外的所有控制器输入"。

| 字段 | 范围 | 含义 |
|---|---|---|
| **control（CC 号）** | 0-127 | 哪个控制器 |
| **value** | 0-127 | 控制器当前值 |

#### 常见 CC 号含义（GM 标准）

| CC 号 | 名称 | 用途 |
|---|---|---|
| 1 | Modulation Wheel | 颤音/调制轮 |
| 7 | Volume | 音量 |
| 10 | Pan | 左右声像（64=居中） |
| 11 | Expression | 表情踏板 |
| 64 | Sustain Pedal | **延音踏板**（≥64=踩下，<64=松开） |
| 66 | Sostenuto | 持续音踏板 |
| 67 | Soft Pedal | 柔音踏板 |
| 91 | Reverb Send | 混响发送量 |
| 123 | All Notes Off | 所有音符止音 |
| 其他 | 未标准分配 | 厂商自定义按钮/踏板 |

#### CC 的两种形态

| 形态 | 行为 | 例子 |
|---|---|---|
| **开关型** | 只有 0 和 127 两个值 | 延音踏板：踩=127，松=0 |
| **连续型** | 0-127 连续 | 音量推子、弯音轮、表情踏板 |

### 🟡 Pitch Bend — 弯音

```
字节: 0xE0 + channel  | LSB  | MSB
日志: pitch_bend ch0 pitch=8192
hex : E0 00 40
```

| 字段 | 范围 | 含义 |
|---|---|---|
| **pitch** | 0-16383（14-bit 高精度） | 8192=居中（不弯），<8192=降音，>8192=升音 |

### 🟡 Program Change — 音色切换

```
字节: 0xC0 + channel  | program
日志: program_change ch0 program=0
hex : C0 00
```

| 字段 | 范围 | 含义 |
|---|---|---|
| **program** | 0-127 | 切换到第 N 号音色（GM 标准里 0=钢琴，24=吉他，33=贝斯...） |

### 🟡 Aftertouch — 触后

键盘**按住之后再用力按**产生的额外压力信息。分两种：

| 类型 | 字节 | 含义 |
|---|---|---|
| Channel Aftertouch | 0xD0 + channel + pressure | 整个通道的平均压力 |
| Poly Aftertouch | 0xA0 + channel + note + pressure | 某个特定音符的压力 |

## 五、原始 Hex 速查

日志里 `raw_hex` 列显示的就是这三个字节。快速对照：

| hex 前缀 | 类型 |
|---|---|
| `90`~`9F` | Note On（通道 0-15） |
| `80`~`8F` | Note Off |
| `B0`~`BF` | CC |
| `E0`~`EF` | Pitch Bend |
| `C0`~`CF` | Program Change |
| `D0`~`DF` | Channel Aftertouch |
| `A0`~`AF` | Poly Aftertouch |

**例子**：`B0 15 7F`

- `B0` = CC，通道 0
- `15` = 十进制 21（CC#21）
- `7F` = 十进制 127（最大值）

## 六、绑定 CC 时的 value_min 过滤

CC 控制器通常发两条消息：**踩下（127）+ 松开（0）**。如果不加区分，绑定动作会被触发两次。

解决方法是在绑定源里设置 `value_min`（数值下限）：

| value_min | 效果 |
|---|---|
| 不设（None） | 所有值都命中 |
| 64 | 只有 value ≥ 64 才命中（踩下=127 命中，松开=0 不命中） |
| 1 | 只要 value ≥ 1 就命中 |

这对所有 CC 控制器都适用，包括延音踏板（CC#64）、表情踏板、音量推子等。

## 七、一个完整琴键的 MIDI 生命周期

弹一个 C4 中央 C（note=60），力度中等（velocity=80），按住 2 秒，松开：

```
t=0.000  →  90 3C 50  →  note_on  ch0  note=60  vel=80    ← 按下
t=2.000  →  80 3C 40  →  note_off ch0  note=60  vel=64    ← 松开（release velocity 固定 64）
```

同时如果踩了延音踏板（CC#64）：

```
t=0.500  →  B0 40 7F  →  cc ch0 cc=64  val=127   ← 踩下延音
t=1.500  →  B0 40 00  →  cc ch0 cc=64  val=0     ← 松开延音
```

延音踏板的效果是：即使你松了琴键（收到 Note Off），音符继续响，直到你松延音踏板（收到 CC#64=0）。

## 八、note 音符号对照表

| note 值 | 音名 | octave |
|---|---|---|
| 0 | C | -1 |
| 1 | C# / Db | -1 |
| 2 | D | -1 |
| ... | ... | ... |
| **60** | **C (中央 C)** | **4** |
| 61 | C# | 4 |
| 62 | D | 4 |
| 63 | D# | 4 |
| 64 | E | 4 |
| 65 | F | 4 |
| 66 | F# | 4 |
| 67 | G | 4 |
| 68 | G# | 4 |
| 69 | A | 4 |
| 70 | A# | 4 |
| 71 | B | 4 |
| 72 | C | 5 |
| ... | ... | ... |
| 127 | G | 9 |

计算公式：`octave = note // 12 - 1`，`半音 = note % 12`（0=C, 1=C#, 2=D...）。

## 九、System 消息速览

| hex | 类型 | 用途 |
|---|---|---|
| `F0 ... F7` | SysEx | 厂商专用扩展（大量数据） |
| `F1` | MIDI Time Code Quarter Frame | 时间码同步 |
| `F2 LSB MSB` | Song Position | 歌曲位置指针（鼓机/序列器） |
| `F3` | Song Select | 选第几首 |
| `F8` | Clock | 时钟同步（24 拍/四分音符） |
| `FA` | Start | 开始播放 |
| `FB` | Continue | 继续 |
| `FC` | Stop | 停止 |

一般人不需要碰这些——除非你在做鼓机同步或 SysEx 固件升级。
